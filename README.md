# color king（Godot MVP）

一款竖屏休闲逻辑谜题原型。玩家需要在彩色区域棋盘上找出皇冠，同时满足每行、每列、每个颜色区域各一个皇冠，且皇冠不能八方向相邻。

## 当前版本改动

本仓库基于 `jydoit/sudoku_test` 扩展，当前版本主要做了这些更新：

- App 名称和首页主视觉更新为 `color king`
- 首页改为与关卡结果页一致的蓝色主色系，突出皇冠主视觉、开始关卡和新人流程入口
- 关卡页保留核心棋盘规则，并提供返回首页、金币、红心、帮助、设置和选关入口
- 棋盘底色为白色；不同颜色区域边缘和棋盘最外缘使用深色边框，同色区域内部使用同色加深缝隙，全部按整数像素对齐
- 正式关卡底部显示清除、皇冠直找和提示三个道具按钮
- 正式关卡按标准答案判定皇冠尝试；非答案格会扣除红心并标记不可修改的红色 X
- 皇冠视觉统一改为戴皇冠的小狮子贴图，普通皇冠、提示皇冠、错误皇冠和通关展位使用同一角色的不同状态
- 皇冠直找按钮：用户初始 3 次，点击后直接找到一个皇冠，免费次数用完后按当前关卡价格消耗金币
- 清除按钮为永久免费道具，可清除普通 X、普通皇冠和错误红色 X，保留提示皇冠和皇冠直找生成的锁定皇冠
- 提示和新人引导使用整盘灰色浮层弱化非提示空格；提示相关格和已有 X/皇冠保持正常亮度，不加高亮框、不闪烁
- 正式关卡提示不显示解释文字，只通过棋盘可操作范围表达，提示目标只包含可画普通 X 的非皇冠格
- 关卡结果页改为蓝色整屏奖励页：顶部显示“太棒了！/ 第 X 关 已完成”，中部显示皇冠展位，底部保留“下一关”和“主菜单”
- 关卡失败页沿用蓝色整屏结构，提供金币复活和重新挑战
- 金币经济由关卡尺寸、开局提示皇冠、错误次数和道具动态价格共同决定
- 新增多语言、统一游戏内弹窗、音效反馈、Noto Sans 字体和 UI 设计规范
- 关卡结果页不显示排行榜、奖励进度栏和广告位
- 默认关卡扩展到 1670 个，覆盖 5×5 到 9×9 唯一解关卡
- 关卡均标记难度：新手、普通、困难、专家
- 每关预置 `hintSteps` 和完整 `solveSteps`，标记为 `no_guess`，用于记录无需猜测的逻辑解题路径
- 关卡页顶部提供选关入口，方便调试和快速切换关卡
- 增加内置关卡编辑器，可编辑关卡名称、提示文字、颜色区域和答案点位
- 增加编辑器入口按钮，可从主界面进入编辑器
- 更新冒烟测试，覆盖关卡数据结构、答案合法性、唯一解和无猜解题路径检查
- 新增编辑器冒烟测试，验证编辑器加载、涂色和答案模式切换

## 运行

项目基于 **Godot 4.7**。使用 Godot Project Manager 导入根目录的 `project.godot`，然后点击运行即可。

macOS 也可以直接执行：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --editor --path .
```

无界面启动检查：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --quit-after 5
```

完整冒烟测试：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script res://tests/smoke_test.gd
```

## 已实现

- 竖屏移动端 UI：首页、关卡页、新手引导、提示交互和通关结果页
- 休闲闯关首页：`color king` 主视觉、当前关卡入口和新人流程入口
- JSON 关卡加载，内置 1670 个 5×5 到 9×9 唯一解关卡
- 棋盘交互：单击标记/取消排除 X，双击尝试皇冠，非标准答案格会扣除红心并标记不可修改的红色 X
- 棋盘视觉：白色底板、整数像素对齐，不同颜色区域边缘和棋盘外缘使用深色边框，同色区域内部使用同色加深缝隙
- 行、列、颜色区域和八方向相邻的即时冲突提示
- 正式关卡按展示关卡序号分配红心：第 1-10 关 3 个，第 11-30 关 2 个，第 31 关起 1 个；红心归零时显示失败页
- 皇冠直找道具：初始 3 次，直接放置一个锁定皇冠；免费次数耗尽后显示金币价格
- 免费清除道具：清除普通 X、普通皇冠和错误红色 X，保留锁定提示皇冠
- 教学提示、通关奖励、金币复活、下一关和主菜单回流
- 正式关卡提示只给出当前可排除的非皇冠格，玩家单击目标格画普通 X 推进棋盘
- 提示支持候选锁定、成组锁定、反证排除和直接冲突排除
- 提示时非提示空格被灰色浮层弱化且不可点击，提示相关格和已有标记保持正常亮度
- 结果页：通关和失败都使用蓝色整屏反馈；通关可进入下一关或主菜单，失败可金币复活或重新挑战
- 本地保存当前关卡、棋盘、金币、提示次数、皇冠直找次数、经济统计和完成记录
- 多语言与字体：随包发布 Noto Sans SC 和 Noto Sans Arabic，支持中文、英文、法语和阿拉伯语 RTL
- 音效反馈：普通 X、取消、清除、正确皇冠、错误皇冠、红心损失、提示、皇冠直找和通关均有轻量音效
- 内置关卡编辑器，支持调整区域和答案点位
- 预留主题入口；棋盘和关卡结构支持任意 N×N 扩展

## 代码结构

```text
AGENTS.md                  项目协作、文档和测试规则
data/levels.json           关卡配置
docs/PRODUCT_REQUIREMENTS.md 产品需求文档与回归测试清单
docs/CODEX_TODO.md         Codex 后续优化待办记录
scenes/main.tscn           主场景
scenes/level_editor.tscn   关卡编辑器场景
scripts/main.gd            UI、游戏状态、规则、存档与通关流程
scripts/game_board.gd      自绘响应式棋盘与点击反馈
scripts/coin_economy.gd    金币奖励、道具价格、复活和经济统计
scripts/dialog_controller.gd 统一游戏内弹窗
scripts/localization_controller.gd 多语言与 RTL 控制
scripts/audio_controller.gd 音效反馈控制
scripts/ui_tokens.gd       共享 UI、棋盘和动效设计参数
scripts/level_editor.gd    关卡编辑器逻辑
scripts/level_store.gd     JSON 加载与基础数据校验
tests/smoke_test.gd        核心流程冒烟测试
tests/editor_smoke_test.gd 编辑器冒烟测试
```

新增关卡时在 `data/levels.json` 中加入配置即可。`solution` 用于提示系统和正式关卡的皇冠尝试判定；通关仍要求玩家摆放满足行、列、颜色区域和相邻规则。
