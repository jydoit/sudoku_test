## 2026-07-23

### UI 与玩法更新

- 统一 PRD、UI 规范、项目约束和 README，清理旧皇冠、清除/撤销、金币复活、旧色板和旧提示样式描述。
- App 名称和首页主视觉更新为 `color king`。
- 首页改为蓝色主色系，只突出胜利小狮子主视觉、开始关卡和新人引导入口。
- 棋盘 UI 按最新规则落地：白色底板、10 色亮色板、只有棋盘最外框使用深色线，不同颜色区域之间不画深色线，所有格子之间保留白色格间距，并保留轻量底纹。
- 正式关卡底部只显示“小狮子”和“提示”两个道具按钮。
- 小狮子视觉统一使用戴皇冠的小狮子贴图，正确小狮子、提示小狮子、开局小狮子和结果页使用同一角色体系。
- 已确认小狮子、提示小狮子、开局小狮子和错误红 X 全部锁定；普通 X 仍可单击或滑动取消。
- 正式关卡按标准答案判定小狮子尝试；非答案格会扣除红心并标记不可修改的红色 X。
- 正式关卡分段红心规则落地：第 1-10 关 3 个，第 11-30 关 2 个，第 31 关起 1 个。

### 提示、引导与反馈

- 正式关卡提示改为半透明白灰蒙层：提示相关格和已有标记保持正常亮度，非提示区域不可点击，不显示解释文案，不加高亮框、不闪烁。
- 小狮子直找按钮初始 3 次，点击后直接找到一个标准答案小狮子；免费次数用完后按当前关卡价格消耗金币。
- 补齐反馈表现：正确找到小狮子有弹性出现动效，错误红 X 有短震动反馈，停顿思考约 8 秒后已出现的小狮子会轻微摇头。
- 新手教程可见流程与正式关卡两按钮布局对齐，旧撤销/清除教学入口禁用。

### 结果页与经济

- 通关结果页改为蓝色整屏奖励页：顶部显示“太棒了！/ 第 X 关 已完成”，中部显示胜利小狮子，底部保留“下一关”和“主菜单”。
- 关卡失败页沿用蓝色整屏结构，中部显示失败小狮子，提供“重新挑战”和“返回首页”。
- 关卡结果页不显示排行榜、奖励进度栏和广告位。
- 金币经济由关卡尺寸、开局提示小狮子、错误次数和道具动态价格共同决定。

### 数据、编辑器与测试

- 默认关卡扩展到 1670 个，覆盖 5x5 到 9x9 唯一解关卡。
- 关卡均标记难度：新手、普通、困难、专家。
- 每关预置 `hintSteps` 和完整 `solveSteps`，标记为 `no_guess`。
- 关卡页顶部提供选关入口，使用每页 20 关、每行 5 个的大触控数字宫格，并以数据 `levelId` 统一列表、标题和存档编号。
- 增加内置关卡编辑器，可编辑关卡名称、提示文字、颜色区域和答案点位。
- 更新冒烟测试，覆盖关卡数据结构、答案合法性、唯一解和无猜解题路径检查。
- 新增教程、存档兼容和编辑器相关自动测试。
