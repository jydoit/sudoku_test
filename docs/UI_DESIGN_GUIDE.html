1. 设计目标

  • 轻松、明亮、治愈，降低逻辑谜题压力。
  • 棋盘信息清晰，不依赖颜色也能区分区域。
  • 关卡页优先服务解题；首页和结果页负责情绪与入口。
  • 按钮足够大，反馈轻量但明确。

必须满足

  • 棋盘保持正方形，起点和尺寸使用整数像素。
  • 每个格子等宽等高，独立圆角矩形。
  • 格间距露出白色底板，不能合并成大色块。
  • 不同颜色区域之间不画深色线；棋盘最外缘也不画深色外框；颜色底纹需要更明显但不能压过小狮子和 X。
  • 小狮子、普通 X、错误红 X 都居中，不能撑大格子。
  • 错误红 X 约占格子 70%，锁定不可修改。

提示态规则

  • 一次性显示所有可操作提示格，保持正常亮度。
  • 不加高亮框、不闪烁、不逐个显示。
  • 非提示格覆盖半透明白灰遮罩，仍能看出原颜色轮廓。
  • 已标记小狮子、普通 X、错误红 X 不被遮罩。
  • 非提示区域不可点击。

5. 按钮和顶部信息

顶部

  • 首页、金币、3 个红心、帮助、设置、选关保持同一视觉层级。
  • 空心红心大小必须和实心红心一致，只改变填充状态。
  • 金币图标使用透明 PNG，不退化为文字符号。

底部

  • 只保留“小狮子直找”和“提示”两个按钮。
  • 两个按钮并列、等宽、图标在上，文字和次数在下。
  • 次数清楚显示，用完进入禁用或价格状态。

9. 发布前验收标准

只要涉及 UI、视觉素材、动效、音效、页面布局、棋盘绘制、按钮状态、提示蒙层或结果页，打包/发布前必须截图验收，不能只用自动测试替代视觉检查。
  • 首页：标题、胜利小狮子、开始关卡、新人引导、无多余入口。
  • 正式关卡：顶部金币/红心/帮助/设置/选关，底部只有两个道具按钮。
  • 棋盘空态：白色底板、圆角格、10 色、区域无深色分割线。
  • 棋盘标记态：普通 X、小狮子、错误红 X 居中且尺寸正确。
  • 提示态：非提示格白灰遮罩，提示格正常亮度且可点击。
  • 结果页：成功/失败页面蓝色体系，小狮子全身图，按钮清楚。
  • 弹窗：游戏内遮罩和圆角卡片，不使用系统默认窗口外观。
  • 多语言：中文、英文、阿拉伯语、法语、拉丁语不裁切。
  • 截图：优先使用原尺寸图；缩放时必须说明比例并检查原图。
  • 交付：列出通过项、不一致项、未验证项、截图/设备/包版本、是否允许发布。
